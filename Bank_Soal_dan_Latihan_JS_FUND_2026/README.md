## 📑 Penjelasan Detail Pemisahan Kategori

### 1. Kuis Materi (Micro Lessons)
- **Letak:** Tab ke-2 di Master Excel / File `01_Kuis_Materi_Micro_Lessons`
- **Tujuan:** Menguji pemahaman teori dan konsep siswa setelah membaca materi di setiap Micro Lesson.
- **Isi:**
  - Identitas Minggu & Nama Kuis (contoh: *Kuis ML1.1 - Apa itu JavaScript?*)
  - Nomor Soal
  - Kalimat Pertanyaan
  - Pilihan Jawaban A, B, C, D
  - **Kunci Jawaban Benar** (diberi tanda dan warna hijau)
  - **Pembahasan / Feedback** edukatif untuk siswa.

### 2. Latihan AICode (Praktik Micro Lesson)
- **Letak:** Tab ke-3 di Master Excel / File `02_Latihan_AICode_Praktik_Micro_Lessons`
- **Tujuan:** Latihan menulis kode praktis secara langsung di lingkungan coding interaktif AICode.
- **Karakteristik AICode:** Menggunakan **Mode: TRAINING** (fitur AI Hint aktif membantu siswa saat stuck).
- **Isi:**
  - Identitas Minggu & Nama Praktik (contoh: *Praktik ML1.1 - Hello World*)
  - Instruksi / Deskripsi Tugas
  - Starter Code (kode awal yang disediakan untuk siswa)
  - Testcase Validasi Otomatis (input & expected output)
  - **Kode Solusi Ideal** (kunci jawaban kode resmi guru)
  - Catatan Penilaian Guru.

### 3. Weekly Quiz (Kuis Mingguan)
- **Letak:** Tab ke-4 di Master Excel / File `03_Weekly_Quiz`
- **Tujuan:** Evaluasi kognitif komprehensif di setiap akhir pekan belajar (Minggu 1 s/d Minggu 8).
- **Isi:**
  - 10 butir soal pilihan ganda berbobot per minggu (total 80 soal)
  - Pilihan Jawaban A, B, C, D
  - **Kunci Jawaban Benar**
  - **Pembahasan / Feedback Lengkap**.

### 4. Ujian AICode (Weekly Assignment & Final Project)
- **Letak:** Tab ke-5 di Master Excel / File `04_Ujian_AICode_Weekly_Assignment_dan_Final_Project`
- **Tujuan:** Ujian praktikum coding untuk menguji kemampuan mandiri siswa tanpa panduan hint AI.
- **Karakteristik AICode:** Menggunakan **Mode: EXAM** (fitur AI Hint dinonaktifkan).
- **Isi:**
  - 8 Weekly Assignment (Minggu 1 s/d Minggu 8)
  - 1 Final Project JavaScript Fundamental (Mini Todo Application)
  - Deskripsi Tugas & Rubrik Penilaian Persentase
  - Starter Code
  - Testcase Validasi Otomatis
  - **Kode Solusi Ideal Guru**
  - Catatan Penilaian & Petunjuk Eksekusi.
