Course ini membekali siswa SMK Kelas 11 (Fase F) Jurusan PPLG dengan fondasi JavaScript dari nol. ### MICRO LESSON 2.1 — Variabel di JavaScript

**3. Judul Halaman:** ML2.1 - Variabel di JavaScript  
**4. Intro:** Pelajari cara menyimpan data dengan `let` dan `const`.  
**5. Materi (≤300 kata):**

**Variabel** = wadah menyimpan data. Deklarasi modern:
```javascript
let umur = 17;        // bisa diubah
const jurusan = "PPLG"; // tidak boleh diubah
```

```javascript
let nilai = 80;
```

```javascript
const NIS = "12345";
// NIS = "999"; // ERROR
```

### MICRO LESSON 2.2 — Tipe Data String

```javascript
let nama = "Siti";
```
