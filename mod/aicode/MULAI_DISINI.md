## 👋 Selamat Datang!

Anda sedang melihat plugin **AICode** - sebuah activity module Moodle untuk pembelajaran programming dengan AI-powered feedback.

**Dokumentasi ini dalam Bahasa Indonesia** dan berisi **12 quiz JavaScript siap pakai**!

---

## ⚡ Quick Start (2 Menit)

### Untuk Guru:

1. **Buka file ini di browser:**

   ```
   mod/aicode/examples/quiz_gallery.html
   ```

2. **Pilih quiz** yang Anda inginkan

3. **Klik "Lihat Detail & Copy"**

4. **Paste ke Moodle** saat membuat AICode activity

5. **Done!** ✅
