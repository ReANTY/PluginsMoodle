Lampiran 1 Instrumen Tes Kemampuan Pemrograman (JavaScript)

Tes Kemampuan Pemrograman JavaScript

Pretest & Posttest — Pembelajaran dengan Plugin Moodle AICode

Konteks:Siswa SMK; kelompok eksperimen (umpan balik LLM) vs kontrol (tanpa LLM); keduanya memakai modul AICode.
Tujuan:Mengukur kemampuan dasar algoritme dan pemrograman JavaScript sebelum dan sesudah intervensi.
Etika:Informasikan bahwa kode dapat diproses sistem; patuhi izin sekolah dan orang tua wali.

Spesifikasi tes

AspekKetentuan
Waktu60–90 menit (sesuaikan jam pelajaran)
LingkunganKertas atau editor teks tanpa AI; boleh menuliskan console.log sebagai komentar penjelasan
CakupanVariabel, tipe data, operator, percabangan, perulangan, fungsi, array dasar
Tidak wajibDOM, framework, modul ES

Rubrik penilaian (per butir skor 0–4)

SkorDeskripsi
4Solusi benar, logika tepat, sintaks wajar
3Solusi hampir benar, kesalahan kecil (mis. off-by-one)
2Solusi sebagian, pemahaman parsial
1Usaha minimal, banyak kesalahan konsep
0Kosong atau tidak relevan

Indikator debugging (opsional): +1 maksimum per soal jika siswa menuliskan langkah menemukan kesalahan atau tes kasus pada soal perbaikan kode.

Set A — Pretest

No Pertanyaan / perintah Ruang jawaban Skor
(0–4)
1 Jelaskan perbedaan let dan const dalam JavaScript. Berikan satu contoh penggunaan masing-masing (boleh pseudokode singkat). (20 poin)
2 Tuliskan fungsi jumlahGanjil(n) yang mengembalikan jumlah bilangan ganjil dari 1 sampai n (inklusif). Contoh: jumlahGanjil(5) → 9. (20 poin)
3 Temukan kesalahan potongan kode berikut; tuliskan kode yang sudah diperbaiki. (20 poin) 
function cekDiskon(total) {
  if total > 100000 {
    return total * 0.1;
  }
  return 0;
}
4 Tuliskan program yang mencetak atau mengembalikan string deret: 2, 4, 8, 16, 32 menggunakan perulangan (for atau while). (20 poin)
5 Diberikan array let nilai = [70, 85, 60, 90]; tuliskan kode untuk menghitung rata-rata dan menampilkan hasil (console.log atau return). (20 poin)

Set B — Posttest

No Pertanyaan / perintah Ruang jawaban Skor
(0–4)
1 Jelaskan kapan memakai const dibanding let untuk variabel yang menampung array; apakah isi array masih dapat diubah? (20 poin)
2 Tuliskan fungsi jumlahGenap(n) menjumlah bilangan genap dari 1 sampai n (inklusif). Contoh: jumlahGenap(5) → 6. (20 poin)
3 Perbaiki kode berikut agar valid dan logis. (20 poin) 
function sapa(nama) {
  console.log("Halo, " nama);
}
4 Dengan perulangan, cetak deret: 3, 6, 12, 24, 48. (20 poin)
5 Dari let harga = [10000, 25000, 15000]: hitung total, terapkan diskon 15% jika total > 30000; tampilkan total akhir. (20 poin)

Gunakan aktivitas AICode di course Moodle untuk perlakuan; tes terpisah ini untuk pengukuran. Selaraskan isi tes dengan capaian pembelajaran course JavaScript Anda.

Perhitungan skor SUS (standar):
Butir ganjil (1,3,5,7,9): skor butir = (nilai dipilih − 1). Butir genap (2,4,6,8,10): skor butir = (5 − nilai dipilih).
Jumlahkan sepuluh butir × 2,5 = skor SUS 0–100 (~68 acuan industri; >80 baik; <50 perlu perbaikan besar).
