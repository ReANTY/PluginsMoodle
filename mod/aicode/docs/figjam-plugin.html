FigJam Plugin

📐 Buat Diagram AiCode di FigJam

Plugin ini akan membuat diagram alur kerja plugin AiCode secara otomatis di dalam FigJam, lengkap dengan semua node, panah, warna, dan label yang terstruktur rapi.

⚠️ Syarat Wajib: Figma Desktop App
Plugin development tidak bisa dilakukan di browser. Kamu harus install Figma Desktop App terlebih dahulu, lalu buka file FigJam dari dalamnya.
📍 Jalur Menu yang Benar
☰ Main Menu → Plugins → Development → + New plugin...
☰ Main Menu = ikon logo Figma di pojok kiri atas (bukan "Resources").
Alternatif: Klik kanan di canvas FigJam → Plugins → Development → New plugin...
1

Install Desktop App

Download & install Figma Desktop dari figma.com/downloads. Buat/buka file FigJam.

2

Buka Plugin Dev

Klik logo Figma (☰) di pojok kiri atas → Plugins → Development → New plugin...

3

Pilih FigJam

Beri nama bebas, pilih editor type "FigJam", klik Save. Folder plugin terbuka otomatis.

4

Ganti code.js

Buka folder plugin, hapus isi code.js bawaan, tempel kode di bawah, lalu Run.

💡 Tidak punya Desktop App? Gunakan metode SVG Import yang jauh lebih mudah: buka figma-export.html, download file SVG-nya, lalu drag & drop ke FigJam browser. Hasilnya hampir sama ✓
